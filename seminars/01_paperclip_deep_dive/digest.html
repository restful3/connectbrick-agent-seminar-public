Weekly Digest

1줄 thesis — 능력 경쟁은 끝났고, 코디네이션이 새 병목 이다.

본 글은 커넥트브릭 격주 세미나 Session 1 의 사전 읽기 자료다. 본 세션의 메인 주제(에이전트 패러다임 비교 + Paperclip 심층 분석)에 들어가기 전, 청중이 30분 안에 훑어 2026년 5월 시점 에이전트 생태계의 큰 그림을 잡을 수 있도록 정리했다.

5 메타 트렌드 (2026 5월)

1. 멀티에이전트 프레임워크의 패러다임 분화

2025년까지 "에이전트 프레임워크" 라는 한 덩어리였던 영역이 2026년에는 그래프형(LangGraph) / 역할극형(CrewAI·AutoGen) / skill 중심(Deep Agents·Claude Agent SDK) / 조직형(Paperclip) 으로 분명히 갈렸다. 더 이상 "어떤 프레임워크를 쓰지" 가 취향 문제가 아니라 "우리 워크플로의 모양이 그래프냐, 역할극이냐, 회사냐" 라는 질문이 됐다. LangChain 설문(n=1,340) 기준 production 진입률 57% (1만 명+ 대기업은 67%)에 도달했다.

2. MCP(Model Context Protocol)의 사실상 표준화

2024년 11월 Anthropic이 발표한 MCP가 18개월 만에 에이전트-도구 인터페이스의 사실상 표준 이 됐다. 공개 MCP 서버 레지스트리는 2025 Q1 1,200개에서 2026년 4월 9,400개+로 늘었고 (월간 +18% 성장), Claude·ChatGPT·Gemini·Cursor·Windsurf·OpenAI Agents SDK 등이 모두 네이티브 채택. "한 번 MCP 서버 만들면 어떤 호스트에서든 붙는다" 가 됐다. 다만 SSO 통합 auth · 감사 로그 · 게이트웨이 정책은 미해결 영역으로 남아 있다.

3. Agent Skills — 프롬프트 자산의 코드화

Anthropic이 2025-12-18 공개한 Agent Skills 오픈 스펙 은 폴더 한 개에 SKILL.md (YAML frontmatter + Markdown 지시문) + 보조 리소스를 담는 단순 포맷이다. 핵심은 staged loading — 메타데이터만 부팅 시 읽고, 호출될 때만 본문이 컨텍스트에 들어가 토큰 비용을 잡는다. 2026-03 기준 32개 도구(Gemini CLI · Cursor · Block Goose · OpenCode 등)가 동일 SKILL.md를 읽는다. 흩어진 프롬프트 라이브러리가 버전 관리 가능한 코드 디렉토리 가 된다.

4. Coding Agent의 성숙 + SDK 가격 재편

Claude Code SDK가 2026-03 Claude Agent SDK 로 개명되며 "코드 전용" 프레임이 떨어져 나갔다. 동일 SDK 위에서 PowerPoint·Excel·Word·PDF 용 pre-built skill이 함께 제공되고, Cursor·Aider·Goose가 같은 SKILL.md 포맷을 공유한다. 한편 2026-06-15부터 SDK·claude -p·GitHub Actions의 subscription 토큰이 별도 $200/월 크레딧 버킷으로 분리되어, 헤비 유저의 실효 비용이 12~175배까지 오르는 정책 변경이 진행 중이다. cost-aware 아키텍처가 필수 가 됐다.

5. 관찰성·평가의 표준화 — OTel + LangSmith 라인

2026-03 LangSmith가 OpenTelemetry full support를 추가하면서 Laminar · Langfuse · LangSmith · Phoenix가 모두 OTLP를 공통 수신 포맷 으로 받게 됐다. 에이전트 trace가 벤더 종속 없이 이식 가능해진 첫 해다. LangChain 설문에서 production 운영 팀의 89%가 observability 도입, 62%는 step·tool call 단위 trace를 본다. production 진입을 가로막는 1위 이유가 "quality"(32%)인데, 관찰성 없는 품질 개선이 불가능하므로 OTel은 사실상 진입 요건.

왜 지금 "에이전트 회사" 인가

위 5 트렌드의 교집합이 "한 사람 + N개 에이전트로 운영되는 회사" 라는 담론이다. 2026-03-04 공개된 오픈소스 Paperclip 이 6주 만에 GitHub 53,000+ stars를 모은 이유는 "에이전트를 더 똑똑하게 만든다" 가 아니라 "에이전트들에게 직책·예산·승인 라인을 부여하고 조직도(org chart) 위에서 운영한다" 는 발상이다. Gartner는 multi-agent 시스템 관련 문의가 2024 Q1 → 2025 Q2 +1,445% 증가 라고 보고했고, SK AX는 "2026년부터 10개 이상 에이전트가 협업하는 시스템이 보편화" 라는 국내 전망을 내놓았다.

F&B 마케팅 자동화 관점 3가지 시드

본격 적용 논의는 본 리포트 5장 — 여기선 시드만.

  1. 조직형 오케스트레이션의 자연스러움 — Paperclip식 org-chart + 예산·승인 라인 모델은 F&B 마케팅의 캠페인 단위 워크플로 + 브랜드 매니저 승인 구조와 mental model이 가장 잘 맞는다 (가설, 청중과 검증).
  2. MCP 서버 = 통합 ROI 최대 영역 — Meta Ads / GA4 / 인스타 DM / Shopify / POS 를 MCP 서버로 한 번 감싸면, 카피라이팅·캠페인 분석·CS 에이전트가 모두 같은 도구를 쓸 수 있다.
  3. Brand 톤 = SKILL.md 로 자산화 — 브랜드 가이드라인·금지어·페르소나를 Agent Skill로 패키징하면 Claude·Cursor·Paperclip 어디서든 동일 톤이 강제된다.

사전 읽기 추천 (선택)

세미나 전 30분 안에 훑어 오면 좋을 자료:

  1. SK AX — 2026 에이전트 AI 트렌드 (한국어, ~10분) — 국내 대기업 시각의 에이전틱 AI 전환 정리. 멀티에이전트 후속 글과 같이 권장.
  2. Anthropic Engineering — Equipping agents for the real world with Agent Skills (영문, ~15분) — Skill 시스템의 가장 정확한 1차 출처.
  3. Paperclip 공식 사이트 + GitHub README (영문, ~10분) — 본 세션 메인 주제. 최소한 README의 "org chart / budget / governance" 섹션은 보고 와 주세요.
