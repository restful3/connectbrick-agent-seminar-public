Section 02 · Frame

프레임워크는 패러다임이다

패러다임 대표 핵심 단위 흐름 표현 거버넌스
그래프형 LangGraph 노드(step) 상태 그래프 + 엣지 엣지에 HITL
역할극형 CrewAI / AutoGen 발언(turn) 역할 + 대화 critic 또는 외부 래퍼
skill 중심 Deep Agents / Claude Agent SDK skill 호출 메인 루프 + staged loading 사용자 코드 가드
조직형 Paperclip 이슈 / 태스크 조직도 + 위임 런타임 강제

이 4-way는 정답 분류표가 아니라, 커넥트브릭 업무를 어느 사고 방식으로 먼저 그릴지 정하는 발표용 판단 프레임입니다.

Section 02 · Decision

조직형이 자연스러운 업무 조건

조건 질문 시스템 요소
프로젝트 단위 산출물 결과물이 이슈처럼 추적되는가 issue / task
사람 승인 라인 외부 공개 전 사람이 반드시 보는가 approval queue
예산 한도 비용 초과가 정책 위반인가 budget hard-stop
병렬 협업 작성·검수·발행이 동시에 도는가 org chart / delegation

이 네 가지가 동시에 있으면, 조직형 사고 방식이 그래프·역할극·skill 중심보다 운영 구조를 더 직접적으로 받아냅니다.

Section 02 · Takeaway

실제 운영은 하이브리드다

기본 뼈대는 조직형으로 두고, 작성 단계는 역할극형, 브랜드 톤은 skill 중심, 승인 라인은 그래프형 체크포인트로 섞을 수 있습니다.
  • n8n / Make / Zapier 같은 시각 워크플로는 반복 파이프라인에 강함
  • Google Antigravity류는 개발자 워크스페이스와 에이전트 관찰 UI에 가까움
  • Paperclip deep dive는 이 하이브리드 구조의 “운영 control plane” 후보로 검토
